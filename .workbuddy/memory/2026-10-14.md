## 本轮修掉的一个真 bug（不是本任务引入的顺手改动）

`cmd/aeval/main.go` 里 `--bare` 与 `--disable-slash-commands` 的默认值被改成 `false`（clean room 默认应
为 `true`，设计约定 11）。后果：`TestCLIReadsTheSkillFlags` 报 skills `Active:true`、
`TestASlashCommandPromptThatCannotResolveIsNotScoredAsARun` 不再打 slash-command 警告。**已改回 true**；
用 `git worktree add /tmp/aeval-head HEAD` 在干净检出上跑过这两条确认是改动引入的。

## 方法论（写进 MEMORY.md）

- **变异脚本必须分类** CAUGHT / MISSED / BROKEN(编译不过) / NOCHANGE(perl 没匹配上) / NOTRUN，只看退出码会
  把编译错算成「抓到」。
- 我第一版「跳过 `SaveReport`」的变异写成 `if err := st.SaveReport(...); err != nil && false` ——
  **init 语句照样执行**，是语义 no-op；两次 MISSED 全是变异写错、不是测试弱。
- 又一次踩 BSD grep：`\|` 交替**静默返回空**（`grep -rn "a\|b"`）。一律用 Grep 工具或 `grep -E`。

## collect 盖机器标识、回放核对（完成）

- 新包 `internal/machine`：`Identity{ID,Hostname,OS,Arch}`，**只比 `ID`**；`ID = sha256("agenteval machine\0"+平台标识)[:16]`
  hex（macOS `IOPlatformUUID` / Linux `/etc/machine-id` / Windows `MachineGuid`）。**读不到就报错，不退回主机名**
  （主机名默认值常相同，退回会在该拒绝时放行）。
- `dataset.Baseline.Machine *machine.Identity`（`json:"machine,omitempty"`）；`session.Options.Machine` 由
  `cmdCollect` 填 `machine.Current()`，读不到 → 警告 + 不盖（不拒绝采集）。
- `runner.CheckMachine(ds)`：`Run` 内在 `Preflight` 前调（不留 run 行）；`cmdRun`、`runSweep` 也提前调 → usage
  error（exit 2）。`Machine == nil` 不检查、**也不探测本机**（无标识的平台照旧能跑老数据集）。
- 已知边界：盖的是**跑 collect 的机器**，转录从别处拷来时盖的是本机。
